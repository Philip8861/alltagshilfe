# Konfigurator – Bilder

Bilder für den Pflegebox-Konfigurator (Seite /pflegebox). Alle Dateien hier ablegen.

## Erwartete Dateien

| Dateiname | Verwendung |
|-----------|------------|
| **box.webp** | Icon „Meine Pflegebox“ (Box mit Badge) |
| **Pflegeboxi.webp** | Avatar Pflegeboxi (Chatbot). Fallback: **pflegeboxi.png** |
| **EUMEPRO_OP-Maske_Typ_IIR.png** | Standard-Artikel (Mundschutz), 5 € |
| **Duozid_Gebrauchsfertige_Desinfektionstücher_zur_Hände-und_Oberflächendesinfektion.webp** | Standard-Artikel (Desinfektionstücher), 5 € |
| **Hygostar_Latzschuerze_115x90cm_wiederverwendbar.webp** | Hygostar Latzschürze 115×90 cm wiederverwendbar (5 €) |

Artikelbilder, die im Artikel-Tool eingetragen werden (z. B. „flaeche_500ml.png“), können ebenfalls hier abgelegt werden; im Konfigurator dann den Dateinamen oder den Pfad `images/Dateiname.png` angeben.
