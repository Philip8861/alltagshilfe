# Standort-Bilder (PLZ-Finder)

Bilder, die im Standort-Popup (PLZ-Suche auf der Kontaktseite) angezeigt werden.

| Datei | Verwendung |
|-------|------------|
| **standort_bild.webp** | Standort Memmingen (z. B. PLZ 87700) |
| **standort_bild_mindelheim.webp** | Standort Mindelheim (optional) |
| **standort_bild_kaufbeuren.webp** | Standort Kaufbeuren (optional) |

Bitte **standort_bild.webp** für Memmingen in diesen Ordner legen. Die anderen Dateien können bei Bedarf ergänzt werden – fehlende Bilder werden im Popup einfach weggelassen.
